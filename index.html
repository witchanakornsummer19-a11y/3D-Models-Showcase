วิธีติดตั้งลงหน้าจอโฮม iPad (ทำครั้งเดียว):
  1. เปิดหน้าเว็บ 3D Models Showcase ใน Safari บน iPad (ผ่านลิงก์ HTTPS เช่น GitHub Pages)
  2. แตะปุ่ม แชร์ (Share ⬆️) ที่แถบด้านบนขวาของ Safari
  3. เลื่อนลงแล้วเลือก เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)
  4. กด เพิ่ม (Add) จะได้ไอคอน 3D Models Showcase บนหน้าจอโฮม กดเปิดใช้งานได้ทันที
